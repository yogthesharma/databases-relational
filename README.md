# Relational Databases

Standalone learning repo. Work here on its own — no other repos required.

**Phase (for your own roadmap):** Data

## Context

SQL databases are still the default for most product data. Joins, indexes, transactions, and query plans decide whether your app is correct and fast. Learn them here as a standalone skill.

This repository is the single place for everything related to **Relational Databases**: notes, exercises, and small projects. Clone it, open it, and treat it as a complete unit of study.

## Scope

- SQL: SELECT, joins, aggregations, subqueries
- Indexes and when they help (or hurt)
- Transactions and ACID
- Normalization and schema design tradeoffs
- Reading query plans (EXPLAIN)
- Constraints, keys, and data integrity

## Outcomes

When you are done with this repo, you should be able to:

- Design a normalized schema and query it efficiently
- Use transactions correctly for multi-step updates
- Interpret a query plan and fix an obvious slow query

## How to work in this repo

1. Read / write concept notes under `notes/`.
