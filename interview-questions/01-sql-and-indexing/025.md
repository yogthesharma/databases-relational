# Question 025: Set Operations: UNION vs UNION ALL Plans

## Context
A search endpoint concatenates results from `users` and `organizations` name matches:

```sql
(
  SELECT id, name, 'user' AS kind FROM users WHERE name ILIKE $1
)
UNION
(
  SELECT id, name, 'org' AS kind FROM organizations WHERE name ILIKE $1
)
ORDER BY name
LIMIT 20;
```

Latency is high; removing the duplicate-elimination (`UNION ALL`) is suggested.

## Interviewer Prompt
1. Explain the plan cost difference between `UNION` and `UNION ALL`.
2. When is duplicate elimination required here, and when is it wasted work?
3. How would you restructure ranking/pagination across two sources for predictable performance?
