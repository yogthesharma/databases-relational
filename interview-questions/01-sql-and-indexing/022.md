# Question 022: Parallel Query and When It Hurts

## Context
A large analytical `SELECT` shows `Gather` / `Parallel Seq Scan` in `EXPLAIN`. On a latency-sensitive OLTP box sharing the same instance, app p99 worsens when analysts run these queries. `max_parallel_workers_per_gather` is default-ish.

## Interviewer Prompt
1. Describe when parallel query helps and what resources it consumes.
2. How would you isolate analytical work from OLTP without necessarily buying a new cluster today?
3. What plan or GUC signals would you use to decide parallelism is the culprit?
