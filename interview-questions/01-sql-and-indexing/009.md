# Question 009: DISTINCT ON vs Window Functions for Latest Row

## Context
You need the latest status event per `shipment_id`. Two SQL styles are under review:

```sql
-- Approach A
SELECT DISTINCT ON (shipment_id) *
FROM shipment_events
ORDER BY shipment_id, recorded_at DESC;

-- Approach B
SELECT *
FROM (
  SELECT *,
         row_number() OVER (PARTITION BY shipment_id ORDER BY recorded_at DESC) AS rn
  FROM shipment_events
) t
WHERE rn = 1;
```

A third engineer suggests a self-join against `MAX(recorded_at)` per shipment instead. Table is large; many shipments have long histories.

## Interviewer Prompt
1. Compare `DISTINCT ON`, `row_number()`, and the `MAX` self-join for correctness and typical plan shapes.
2. What supporting index would you want for each approach?
3. If the product later needs "latest event per shipment *within each status family*," how does your preferred approach extend?
