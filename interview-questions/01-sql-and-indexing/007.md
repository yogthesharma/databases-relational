# Question 007: Bitmap Index Scans and Combining Conditions

## Context
You see this plan shape on an analytics-ish filter:

```
Bitmap Heap Scan on customers
  Recheck Cond: ((country = $1) AND (tier = $2))
  -> BitmapAnd
       -> Bitmap Index Scan on idx_customers_country
       -> Bitmap Index Scan on idx_customers_tier
```

Someone argues: "Always replace BitmapAnd with one composite index."

## Interviewer Prompt
1. Explain what a Bitmap Index Scan + Bitmap Heap Scan is doing, including recheck.
2. When is BitmapAnd a healthy choice versus a single composite `(country, tier)` index?
3. What data distribution or selectivity change would make you insist on the composite index anyway?
