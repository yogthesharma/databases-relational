# Question 024: Sort Spill and work_mem Diagnosis

## Context
`EXPLAIN ANALYZE` for a report shows `Sort Method: external merge Disk: 120MB`. The query joins and aggregates a day of events. Increasing `work_mem` session-locally fixes latency, but the DBA refuses to raise the global default.

## Interviewer Prompt
1. Explain what external merge sort implies for I/O and latency.
2. How do you reason about `work_mem` as a per-operation budget across many concurrent sessions?
3. What query or index changes could remove the sort or shrink its memory need without a global GUC change?
