# Question 013: Expression Indexes and Functional Lookups

## Context
Users log in with email. The table stores emails mixed-case; the app always queries:

```sql
SELECT * FROM users WHERE lower(email) = lower($1);
```

There is a unique B-Tree on `email` (raw). Login occasionally seq-scans.

## Interviewer Prompt
1. Why might the unique index on `email` not serve `lower(email) = ...`?
2. Propose an expression index and discuss uniqueness guarantees for case-insensitive emails.
3. What application or constraint changes would you recommend alongside the index?
