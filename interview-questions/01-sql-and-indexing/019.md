# Question 019: Covering Indexes vs Table Bloat from Wide Indexes

## Context
To make a reporting query Index Only Scan friendly, an engineer includes ten wide `text` columns in an index. Writes slow down; vacuum and index bloat grow quickly. The query runs every 15 minutes.

## Interviewer Prompt
1. Trade off covering-index benefits against write amplification for this cadence.
2. What alternative designs (materialized view, summary table, columnar export) would you evaluate?
3. How would you measure whether the covering index is "worth it" in production?
