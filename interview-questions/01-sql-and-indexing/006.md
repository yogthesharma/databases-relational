# Question 006: GiST for Range Overlap Queries

## Context
A booking system stores reservations as ranges:

```sql
CREATE TABLE reservations (
  id          bigserial PRIMARY KEY,
  resource_id bigint NOT NULL,
  during      tstzrange NOT NULL,
  EXCLUDE USING gist (resource_id WITH =, during WITH &&)
);
```

A reporting query finds overlapping bookings for a resource in a window:

```sql
SELECT *
FROM reservations
WHERE resource_id = $1
  AND during && tstzrange($2, $3);
```

## Interviewer Prompt
1. Explain what the `EXCLUDE` constraint is enforcing and how GiST participates.
2. Contrast GiST and B-Tree for overlap (`&&`) predicates—when is each appropriate?
3. If exclude violations become a hotspot under concurrent booking attempts, what symptoms would you expect in `pg_locks` / wait events, and what application-level mitigations would you discuss?
