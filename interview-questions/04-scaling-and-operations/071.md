# Question 071: Index and Table Bloat Measurement

## Context
Disk usage for `orders` grew 3× while logical row count grew 20%. Engineers suspect bloat. Someone wants to run `VACUUM FULL` tonight.

## Interviewer Prompt
1. How would you measure table/index bloat and confirm the diagnosis?
2. Compare `VACUUM FULL`, `CLUSTER`, `pg_repack`, and ordinary vacuum for offline vs online impact.
3. What write patterns created this bloat, and how do you prevent recurrence?
