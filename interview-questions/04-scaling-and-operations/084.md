# Question 084: Multi-Region Topologies Beyond Single Primary

## Context
Leadership wants active-active Postgres in two regions. Engineers propose: single primary + replicas, logical multi-master, or an external distributed SQL layer.

## Interviewer Prompt
1. State the fundamental single-primary limitation for multi-region writes in native PostgreSQL.
2. Compare conflict handling approaches in multi-master / distributed designs.
3. What application invariants become harder once you allow concurrent regional writes?
