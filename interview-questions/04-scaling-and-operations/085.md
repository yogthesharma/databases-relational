# Question 085: Capacity Planning for Connections, CPU, and IO

## Context
Before a marketing launch you must estimate whether the current Postgres instance will survive 5× traffic. You have QPS per endpoint, rough query plans, and pool sizes.

## Interviewer Prompt
1. Build a capacity model linking QPS → connections → CPU/IO.
2. Which experiments (load tests, EXPLAIN on production stats) validate the model?
3. What early warning dashboards would you add for the launch window?
