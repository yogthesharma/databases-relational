# Question 087: Rate Limiting: Database vs Cache

## Context
An API gateway must enforce per-token rate limits (e.g., 100 req/min). Two proposals: Redis sliding window vs PostgreSQL table of counters with `INSERT ... ON CONFLICT` per token bucket.

## Interviewer Prompt
1. Compare correctness, latency, and failure modes of DB-backed vs cache-backed limiters.
2. When is PostgreSQL an acceptable rate-limit store?
3. Design a hybrid approach if you must survive Redis loss without opening the floodgates.
