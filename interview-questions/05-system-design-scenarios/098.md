# Question 098: Search-After-Write for User-Generated Content

## Context
Users create posts stored in Postgres; search is in Elasticsearch via CDC. After submit, the author is redirected to search results that must include their new post within ~1s, while global search can be slightly stale.

## Interviewer Prompt
1. Design a read-your-own-write strategy across DB and search index.
2. How do you handle CDC lag spikes without blocking the publish API?
3. What fallback query path hits Postgres when search is behind?
