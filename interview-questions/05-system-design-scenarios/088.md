# Question 088: Batch Data Archiving Without Locking the Hot Path

## Context
Nightly job archives millions of rows from `events` to object storage, then deletes them. Deletes create WAL spikes, replica lag, and autovacuum storms that hurt daytime OLTP.

## Interviewer Prompt
1. Design a batch archiving pipeline that bounds WAL and lag.
2. How do partition strategies change the design?
3. What correctness checks prove archive completeness before delete?
