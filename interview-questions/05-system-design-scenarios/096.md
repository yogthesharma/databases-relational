# Question 096: Consistent Caching of Personalized Data

## Context
User profile JSON is cached in Redis for 60s. Profile updates hit Postgres then invalidate cache. Users still occasionally see stale profiles across devices; sometimes cache stampedes after expiry.

## Interviewer Prompt
1. Diagnose consistency gaps in cache-aside with TTL-only expiry.
2. Design invalidation / versioning that works with Postgres as source of truth.
3. How do you prevent stampedes for hot keys after invalidation?
