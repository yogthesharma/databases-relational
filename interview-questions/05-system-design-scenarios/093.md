# Question 093: Multi-Tenant Noisy Neighbor Control

## Context
One enterprise tenant runs huge analytical queries on the shared primary, degrading everyone else. RLS is already in place for isolation of rows, not resources.

## Interviewer Prompt
1. What Postgres mechanisms help bound per-tenant resource impact (and what cannot)?
2. Design an architecture (separate queues, replicas, warehouses, quotas) for noisy-neighbor control.
3. How do you attribute cost/load per tenant for enforcement?
