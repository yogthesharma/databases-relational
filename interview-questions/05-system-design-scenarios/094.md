# Question 094: Geospatial Matching with Nearby Search

## Context
A delivery app must find the nearest available couriers within 5km of a pickup point. Table holds millions of courier positions updated frequently.

## Interviewer Prompt
1. Propose a PostgreSQL (+ PostGIS or other) data model and indexing approach.
2. How do high-frequency location updates affect index choice and write load?
3. When do you move active locations out of Postgres into a specialized store?
