# Question 095: Safe Online Backfill of Derived Columns

## Context
You add `orders.search_vector` and must backfill 200M rows while serving traffic. A naive `UPDATE orders SET search_vector = ...` locks and lags replicas.

## Interviewer Prompt
1. Design a chunked backfill compatible with expand/contract migrations.
2. How do you ensure new writes populate the column while old rows catch up?
3. What observability proves the backfill is safe to accelerate or pause?
