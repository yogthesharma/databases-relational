# Question 047: Write-Time Triggers for Audit Trails

## Context
Compliance wants an immutable audit log of changes to `customers`. A trigger writes old/new row images to `customer_audit` on every `UPDATE`/`DELETE`. Writers complain about latency; the audit table grows rapidly.

## Interviewer Prompt
1. Sketch the trigger design and discuss synchronous write amplification.
2. Compare trigger-based audit to application-level event emission and to logical decoding / CDC.
3. What failure modes appear if the audit insert fails mid-trigger?
