# Question 049: Full-Text Search with tsvector and Ranking

## Context
A knowledge-base search must support language-aware stemming, ranking, and phrase search over `title` and `body`. Current `ILIKE '%term%'` plans are unusable at 20M articles.

```sql
CREATE TABLE articles (
  id    bigserial PRIMARY KEY,
  title text NOT NULL,
  body  text NOT NULL
);
```

## Interviewer Prompt
1. Design a `tsvector` + GIN approach (storage, update strategy, query API using `tsquery`).
2. How do you combine rank (`ts_rank` / `ts_rank_cd`) with business boosts (recency, freshness)?
3. When would you outgrow in-database FTS toward an external search system?
