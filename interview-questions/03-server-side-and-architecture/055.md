# Question 055: Materialized Views and Refresh Strategies

## Context
A leaderboard-like aggregate is stored in a materialized view refreshed every 5 minutes with `REFRESH MATERIALIZED VIEW`. During refresh, readers block. Concurrent refresh is proposed.

## Interviewer Prompt
1. Contrast `REFRESH` with and without `CONCURRENTLY` (locks, unique index requirements).
2. When would an incremental summary table maintained by triggers or jobs beat a matview?
3. How do you reason about staleness SLAs versus refresh cost?
