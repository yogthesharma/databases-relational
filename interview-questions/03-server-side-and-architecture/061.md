# Question 061: Connection-Time Session State and Safe Defaults

## Context
App sets `search_path`, `statement_timeout`, `lock_timeout`, and RLS session variables on each checkout from the pool. Misconfiguration caused a production incident where a role saw the wrong schema's tables.

## Interviewer Prompt
1. Which session settings must be set/reset carefully with pooled connections?
2. How do you prevent `search_path` attacks / surprise object resolution?
3. Design a connection initialization checklist for the Node `pg` pool.
