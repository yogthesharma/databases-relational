# Question 064: Logical Decoding / CDC Consumers

## Context
You need to stream document changes to Elasticsearch. Options: trigger → queue table, `LISTEN`, or logical decoding (Debezium-style). Peak write rate is high; consumers can lag.

## Interviewer Prompt
1. Compare trigger fan-out vs logical decoding for CDC.
2. What WAL retention / slot risks appear when consumers stall?
3. How do you guarantee at-least-once delivery and idempotent upserts into the search index?
