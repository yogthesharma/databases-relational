# Question 054: Declarative Partitioning and Local vs Global Indexes

## Context
After partitioning `orders` by month, primary key and unique constraints need redesign. Cross-partition uniqueness on `order_number` alone is required by the business.

## Interviewer Prompt
1. Explain how unique constraints work with declarative partitions.
2. What options exist when a uniqueness requirement spans partitions?
3. How do you plan indexes so pruning still works for the hottest queries?
