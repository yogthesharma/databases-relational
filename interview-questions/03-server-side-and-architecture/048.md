# Question 048: Generated Columns vs Trigger-Maintained Fields

## Context
You need `full_name` always equal to `first_name || ' ' || last_name`, and a `tsvector` search document derived from several text columns. Engineers propose generated columns (stored, and—where the server version supports it—virtual) versus triggers.

## Interviewer Prompt
1. Compare generated columns and triggers for derived data correctness and performance.
2. Which approach fits `full_name`, and which fits a heavy `tsvector` document?
3. What limitations of generated columns (persistence, version support, indexing) affect the write path?
