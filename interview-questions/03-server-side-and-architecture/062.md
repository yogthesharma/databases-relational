# Question 062: Stored Business Logic and Deploy Coupling

## Context
Critical pricing rules live in PL/pgSQL functions deployed via migrations. App deploys and DB migrations are owned by different pipelines and sometimes drift. Debugging production pricing requires reading functions in the DB.

## Interviewer Prompt
1. What operational coupling problems arise when core business rules live in the database?
2. Criteria for keeping logic in SQL vs application code?
3. How would you evolve toward testable, reviewable pricing logic without a big-bang rewrite?
