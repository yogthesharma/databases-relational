# Question 063: JSONB Document Patterns Inside Relational Cores

## Context
Order rows have strict relational money fields, but also a `JSONB` `extras` blob for partner-specific metadata. Some partners now filter and aggregate on keys inside `extras` in hot paths.

## Interviewer Prompt
1. Where do you draw the line between relational columns and JSONB?
2. How do you index and constrain JSONB so bad documents cannot corrupt invariants?
3. Design an escape hatch when a JSON attribute becomes a first-class query dimension.
